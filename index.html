老師 Google 雲端數據資料同步設定

本教學系統支援將學生的「Take history from patient 測試成績資料」自動同步寫入老師的 **Google 試算表 (Google Sheets)**。

網址會儲存在本機瀏覽器中，學生進行測驗後將直接上傳資料。

如何建立 Google Apps Script 自動寫入 "Take history from patient" 成績表？

  1. 開啟新的 Google 試算表，將試算表分頁標籤命名為 Take history from patient。
  2. 於試算表中點選頂部選單 「擴充功能」 -> 「Apps Script」。
  3. 將預設代碼清空，貼上以下代碼：
function doPost(e) {
  var sheet = SpreadsheetApp.getActiveSpreadsheet().getSheetByName("Take history from patient") || SpreadsheetApp.getActiveSpreadsheet().getActiveSheet();
  var data = JSON.parse(e.postData.contents);
  
  // 若為第一筆資料，自動設定標頭
  if (sheet.getLastRow() === 0) {
    sheet.appendRow(["測驗時間", "學生姓名", "科系", "學號", "耗時(秒)", "得分", "測驗主題"]);
  }
  
  sheet.appendRow([
    new Date(),
    data.name,
    data.department,
    data.studentId,
    data.timeSpent,
    data.score,
    "Take history from patient"
  ]);
  
  return ContentService.createTextOutput(JSON.stringify({"result": "success"}))
                       .setMimeType(ContentService.MimeType.JSON);
}
  1. 點選右上角 「部署」 -> 「新增部署」。
  2. 種類選擇 「Web 應用程式」，將「誰有權存取」改為 「任何人 (Anyone)」。
  3. 點選部署授權後，複製產生的 Web App URL，並貼回上方欄位即完成設定！
